# YokaiBeat

YokaiBeat is an Unreal Engine project.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/masterofsea/YokaiBeat.git
   ```

2. Install and enable [Git LFS](https://git-lfs.com/):

   ```bash
   git lfs install
   ```

3. Open the `.uproject` file with the required version of Unreal Engine.

## Git LFS

Unreal Engine assets (`.uasset` and `.umap`) and large binary resources such as textures, audio, video, and 3D models are tracked with Git LFS. Ensure Git LFS is installed before cloning or pushing the project.

## Ignored Files

Generated Unreal Engine directories, including `Binaries`, `DerivedDataCache`, `Intermediate`, and `Saved`, are excluded from version control. They are recreated when the project is built or opened.
